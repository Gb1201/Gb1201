### 📌 Projetos em destaque

#### 🚌 Sistema de Gestão de Vans
Sistema completo para cadastro e gerenciamento de vans escolares, com controle de usuários (responsáveis, motoristas e alunos), rotas, mural de recados e avaliações.
`Java` `Spring Boot` `React`

#### 🔥 Bolão do Mengão
Plataforma para organização de bolões dos jogos do Flamengo. Calcula pontuação dos palpites com base em critérios personalizados e gera ranking em PDF.
`Java` `HTML` `CSS` `Java Swing` `Banco de Dados`

Destaque entre os melhores Trabalhos Interdisciplinares do 1º período da PUC Minas. Projeto em grupo unindo tecnologia e saúde, focado em promover escolhas alimentares inteligentes através de uma plataforma interativa.
